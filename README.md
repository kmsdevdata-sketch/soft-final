# Particle Sphere Demo

대회 시연용 첫 장면입니다. 화면 전체에 입자가 유기적으로 떠다니다가 첫 클릭에 물결치는 구로 모입니다. 이후 구를 클릭하면 클릭한 위치에서 파동이 퍼집니다. `+` 모양 커서는 일반 화살표로 바꿨습니다.

```bash
cd frontend
npm install
npm run dev
```

React + TypeScript + Three.js로 구현했습니다. 구 표면의 입자는 위도별 둘레 길이에 맞춰 배치해 규칙적인 점의 흐름이 보입니다. 초기 유동, 구 표면의 지속적인 파동, 클릭 충격파는 정점 셰이더에서 처리하며 CPU에서 매 프레임 입자 좌표를 갱신하지 않습니다. 밝은 배경과 은색 중심 톤을 유지하고 은은한 색 변화만 추가했습니다.
